# Doctor Inja | دکتر اینجا

> **Project Status: Work in Progress**
>
> A front-end project focused on building a Persian, RTL user interface for doctor search and online appointment booking services.

🔗 **Live Demo:** [doctor-inja.vercel.app](https://doctor-inja.vercel.app/)

📦 **GitHub Repository:** [bootcamp-2024-free-nextjs-FatemehAsi](https://github.com/FatemehAsi/bootcamp-2024-free-nextjs-FatemehAsi)

## About the Project

Doctor Inja is a personal learning project currently under development, built with Next.js and TypeScript. The goal is to create a Persian-language platform interface for searching doctors, medical specialties, and hospitals, while providing a foundation for future online appointment booking features.

The project is not yet complete. Some features are still under development, and the current search interface and displayed information are not connected to a backend service.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm

### Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/FatemehAsi/bootcamp-2024-free-nextjs-FatemehAsi.git
   ```

2. Navigate to the project directory:

   ```bash
   cd bootcamp-2024-free-nextjs-FatemehAsi
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Development Status

Doctor Inja is a personal project under active development. Its structure and features will be gradually improved and expanded. The live demo may not include all the features planned for the final version.
